# Memória

- A experiência é para uma feira escolar na semana seguinte.
- O PDF orienta a dinâmica “O caminho de um dado”: escolha fictícia, rastro, perfil fictício, benefícios/riscos e pergunta final.
- A implementação digital deve tornar a influência visível; não deve ocultar um teste psicológico nem armazenar respostas.
- Não adicionar Firebase, autenticação, banco ou analytics.
- O projeto precisa ser publicável no GitHub e na Vercel como frontend estático.
